# Sentinel AML — Frontend

React + TypeScript + Vite + TailwindCSS dashboard for the AML Suspicious
Activity Detection Agent. See the [root README](../README.md) for full
setup, architecture, and API documentation.

Quick start:
```bash
npm install
npm run dev      # http://localhost:5173, proxies /api -> localhost:8000
npm run build    # type-checks (tsc -b) then builds to dist/
npm run lint     # ESLint (flat config, eslint.config.js)
```
